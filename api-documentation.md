Kuvaus API:sta – Mitä tekee ja mihin käytetään

Perus-URL – API:n juuri (root), esim. https://api.esimerkki.fi

Autentikointi – Jos vaadittu niin dokumentin pitäisi kertoa miten sen saa

Resurssit – Luettelo kaikista API:n tarjoamista resursseista (käyttäjät, tilaukset, tuotteet,…)

HTTP-menetelmät – Mitkä komennot sallittuja ja mitä ne tekevät

Parametrit – Millaisia suodattimia, järjestämisvaihtoehtoja, … pyyntöihin voi lisätä

Esimerkit – Auta käyttäjää ymmärtämään, miten API toimii käytännössä

Virheiden käsittely – Kerro, miten API käsittelee virheitä ja anna esimerkkejä
